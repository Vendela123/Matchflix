# MatchFlix

**Find a movie everyone wants to watch in seconds, not hours.**

MatchFlix helps groups make entertainment decisions instantly. Each person takes a quick preference quiz, and the platform combines everyone's tastes to recommend movies they'll all enjoy. Built for couples, friends, and families tired of endless browsing.

> repeat from then on.

## What & for whom
Movie selection across streaming platforms has become a source of decision fatigue. Groups waste time scrolling catalogs instead of enjoying their evening. MatchFlix solves this by converting individual preferences into group recommendations. Users answer a lightweight quiz about genres, mood, runtime, and language; the platform matches these signals across a movie database and surfaces the best fit for everyone. The product targets casual viewers seeking frictionless group entertainment decisions.

## Stack
Next.js provides the full-stack runtime (server and client). Supabase supplies the PostgreSQL database, real-time subscriptions, and built-in storage. TypeScript ensures type safety across the codebase. Tailwind CSS handles styling; shadcn/ui provides pre-built, accessible components. Vercel hosts the application. TMDb API is queried server-side to fetch movie metadata.

Deploys to Vercel.
